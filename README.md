# ax-route

See what your AI coding agents would cost at API prices, from the logs they already keep on your machine.

```bash
npx ax-route audit
```

No API key, no signup, no config file. Requires Node.js 22.13 or newer.

## What it reads

| Tool | Where |
|---|---|
| Claude Code | `~/.claude/projects/**/*.jsonl` (plus the billing type in `~/.claude.json`) |
| Codex | `~/.codex/sessions` |
| Kimi Code | `~/.kimi-code/sessions` and `~/.kimi` |
| Hermes | `~/.hermes/state.db` (or `$HERMES_HOME`) |
| OpenClaw | `~/.openclaw` (or `$OPENCLAW_STATE_DIR`) |

Only token counts, model names, timestamps and billing mode are used. Prompt and response text is not read into the report.

**Nothing is uploaded.** The audit makes no network requests. It reads local files and prints to your terminal.

## What it prints

```
sources: claude 2 · codex 0 · kimi 0 · hermes 0 · openclaw 0
usage:   2 requests since 2026-09-02

tool          requests     tokens       cost   unpriced
claude               2       8.6k      $0.02          -
```

- **cost is API-equivalent, not your spend.** It is what those tokens would cost at public API list prices from the bundled `config/models.yaml`. If you use a subscription (Claude Pro/Max, ChatGPT plan, Kimi plan), you did not pay this amount. The `--json` output carries each tool's `billing` mode (`subscription`, `api`, `local`, `unknown`).
- **unpriced** counts tokens from models that the bundled price book does not list. They are left out of the cost total, not guessed.
- With no supported logs on the machine it prints `no agent usage found`.

## Options

```bash
npx ax-route audit --json          # machine-readable result
npx ax-route audit --home <dir>    # scan another home directory
```

Global install:

```bash
npm install -g ax-route
ax-route audit
```

## Source

This package is generated by `ax route export` from a private harness repo, using an explicit file allowlist, a TypeScript compile and a gitleaks secret scan. Issues and pull requests: [lpsmurf/ax-route](https://github.com/lpsmurf/ax-route/issues).
